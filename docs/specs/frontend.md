# 前端实现与交互规范

## 1. 页面结构

应用 Shell：顶部是低存在感的创作空间切换与账户菜单，左侧是创作、资产、生成，右侧是主内容。宽屏导航 240px，主区最小宽度 0；小于 768px 改为抽屉，不为窄屏创建第二套业务页面。管理创作空间的页面不展示工作台导航。

| 路由 | 页面职责 | 主要动作 |
| --- | --- | --- |
| /login | 登录表单 | 登录后进入个人创作空间 |
| /studio | 获取或创建个人空间 | 加载、失败重试，成功后进入该空间的工作台 |
| /projects | 管理创作空间 | 切换已有空间、新建标准空间 |
| /projects/:projectId | 工作台 | 在当前空间创作；深链接保持可用 |
| /projects/:projectId/chat/:conversationId? | 会话列表与消息流 | 新会话、发送、引用详情、保存记忆候选 |
| /projects/:projectId/knowledge | 文档列表与入库状态 | 上传、更新版本、查看失败、重试 |
| /projects/:projectId/memory | 记忆卡片/列表 | 确认新增、编辑、修订历史、删除 |
| /projects/:projectId/generation | 生成表单与任务列表 | 选模型、参数、参考图、提交、取消 |
| /projects/:projectId/profile | 个人主页 | 在当前项目工作区内查看账户；图片与视频用标签切换 |
| /projects/:projectId/generation/:taskId | 任务详情 | 真实状态、输出预览、下载、重新生成 |
| /projects/:projectId/assets | 资源库 | 分类、预览、下载、删除 |
| /projects/:projectId/settings | 名称与成员 | OWNER 管理，MEMBER 只读 |

功能未实现时显示明确的未开放状态，不用演示成功数据冒充真实结果。失效的 projectId 回到 `/studio` 并重新获取个人空间，不能把空间列表的第一项当作默认空间，也不能用假项目。切换空间时卸载工作台，清掉不适用的草稿、响应和事件流。上传资料、保存设定和确认记忆尚未实现；实现时必须标明所属创作空间。

账户菜单收起时只显示邮箱首字母，可访问名称仍是「账户菜单」。在项目工作区内展开后，可以进入该项目的个人主页；页面保留工作区侧栏和顶栏，只替换主内容。主内容上方是当前账户，不显示平台角色。下方用标签在图片和视频之间切换，一次只显示一个。个人主页不展示项目内的生成结果。图片标签在内容区中央说明还没有图片作品，并提供进入当前空间创作页的按钮。视频标签仍说明未开放，不请求视频列表。

## 2. 视觉与组件

官网、登录和工作台共用当前深色表面。token 在单一样式入口定义：背景 #10110F，面板 #191B17，正文 #F2F0E9，次级文字 #9B9E92，边框 #3B4032，主色 #D3F96B，主色上的文字 #1A2410，危险色 #F0B4AE，成功色 #C6E27A。状态必须同时有文字/图标，不只靠颜色。

使用系统 sans-serif 字体；正文 14px/1.5，区块标题 18px，辅助文字 12px。登录和工作台标题跟随官网比例，眉题 11px 并拉开字距。间距采用 4/8/12/16/24/32px。主操作按钮高 50px、全圆角；输入框高 40px、圆角 8px；卡片圆角 14px。功能页不得单独硬编码另一套颜色；token 变更在全局完成。

通用组件至少包括 Button、Input、Textarea、Select、Dialog、AlertDialog、Tabs、Badge、Table、Skeleton；业务共享组件为 TaskStatus、EmptyState、ErrorState、AssetPreview、CitationLink，放在所属 feature 的公开导出中。禁止平行重写同名组件。

输入有 label，错误文本绑定 aria-describedby；对话框管理焦点并支持 Esc；破坏性按钮使用 AlertDialog。图标按钮有 aria-label。Markdown 不开启不受控原生 HTML，外链校验协议并隔离新窗口。

## 3. 代码组织

feature 内以 components、hooks、api.ts、types.ts（仅 UI 类型）按需组织；禁止提前创建空层级。React 组件 PascalCase，hooks useXxx，其他变量 camelCase；API DTO 保留 snake_case。跨 feature 只经公开 index.ts 导出，禁止 import 另一 feature 私有文件。

所有网络调用在统一 api 客户端完成：Cookie、CSRF、request_id、超时、AbortSignal、标准错误转换。生成 OpenAPI 类型不能保证运行时安全；对 SSE/未知外部结构使用显式类型守卫，不能用 as 强制断言跳过校验。生成器在前端初始化时选定并锁定，不手改生成代码。

Query key 统一为 ["projects",projectId,resource,...filters]，全局 auth/model 查询独立命名。个人空间获取使用 ["projects","personal"]，按当前登录会话隔离，不接受客户端传入的用户或项目范围。创建项目只提交名称；服务端分配 project_id，创建者成为该项目唯一 OWNER。成功后只把响应写入该项目的详情缓存，并进入 /projects/:projectId，不得把其他项目的查询结果复制进来。项目切换取消请求和 SSE、清理页面临时输入；未提交草稿先提示是否离开。401 清空全部缓存并跳转登录；项目 404 清理对应缓存，防止继续显示已撤权内容。以后的跨空间作品汇总必须由服务端确定可访问范围，缓存键包含登录身份和筛选条件，退出时随全部缓存清理。

不默认乐观更新任务、记忆版本或成员权限。成功后按服务端响应更新或 invalidate；409 展示冲突并保留用户草稿，不能自动覆盖最新内容。

## 4. 关键交互

生成表单根据 capability 渲染参数；模型切换清除不兼容参数并提示。提交前展示最终提示词、模型与参数、参考资源，由用户点击生成。幂等键在一次提交意图开始时生成，网络重试复用；用户编辑后再次提交使用新键。

任务列表默认 3 秒轮询，页面隐藏时降至 15 秒，终态停止；429 按 Retry-After，网络错误退避。用 allowed_actions 决定按钮，但仍处理后端拒绝。cancel_requested 显示“正在请求取消”，reconciliation_required 显示“结果待核对”，不能提供会造成重复收费的自动重试。

SSE 按事件 ID 去重，snapshot 替换而不是追加；completed 后拉取最终消息。断线提示“连接中断，正在恢复”，不自动重新发送消息。失败 partial 文本与完整回答视觉区分。

文档同时展示解析和索引状态；记忆保存有明确确认动作。引用打开对应资料页/段落；已删除来源只显示不可用提示。下载 URL 临近过期重新向后端申请，不长期缓存签名链接。

## 5. 前端验收

用一个真实 feature 页面作为后续参考，不建立另一个演示应用。各页面覆盖 loading/empty/error/success、401/404/409、窄屏和键盘访问。端到端测试覆盖切换项目时旧请求迟到、重复点击生成、SSE 重连、记忆并发编辑、取消未确认、资料索引失败。通过 build/typecheck 不能代替这些业务验证。

## 6. 官网展示层

官网路由 `/` 使用独立 landing feature，保留已有 `/login` 与 `/projects`。官网版式限定在 `.landing` 与官网弹窗。登录页和工作台使用第 2 节的同一套深色 token。官网提供场景分类、参考详情、提示词复制、创作步骤演示、FAQ 和本地灵感草稿。概念素材与演示明确标识，不能伪装真实生成。草稿不持久化、不提交模型请求。详情见 ADR-015。

## 7. 登录入口布局

登录页采用左侧表单、右侧场景轮播，复用既有深色 token。宽度不超过 900px 时隐藏场景区并停止自动轮播。轮播每 7 秒切换，支持前后切换、分页与暂停；鼠标悬停、键盘聚焦、后台页面及减少动态效果偏好时停止自动切换。手动选择后保持暂停，用户可恢复播放。仅展示品牌概念/情绪参考，不冒充实时生成。表单保留既有身份、CSRF、验证和跳转行为；密码显示切换不得提交表单，不新增注册/找回密码或第三方认证。

## 8. 三入口工作区

按用户本次工作区设计要求，项目首页作为“创作”需求输入页，侧栏首期只显示创作、资产、生成三项（各自带图标）。路由分别为 /projects/:projectId、/projects/:projectId/assets、/projects/:projectId/generation。NavLink 根据真实路径设置 aria-current 和深底/品牌色激活态；小屏使用可关闭导航弹窗。侧栏 Logo 回到当前创作空间的创作页。顶部空间菜单默认显示个人空间，并提供切换已有空间、新建创作空间和管理创作空间。

创作预设以类型化本地配置提供，仅填充输入框，不自动发送。后续使用项目级接口替换预设来源，当前不虚构 API。需求预览、复制、草稿清空确认是本地交互；同项目切页保留，项目 ID 改变时销毁状态；刷新提示未保存内容。资产库和视频生成未接入时明确显示 unavailable，不用空数组伪装已查询成功，不展示虚构视频、额度或任务。已指定的视频模型在目录中声明可接收图片时，视频生成可以添加参考图片作为首帧，图片上的生成视频使用同一视频模型；未声明时参考图上传保持关闭。文生视频在已指定 text_to_video 后，时长固定为 5 秒，由用户选择 16:9、9:16、1:1 并明确提交；等待时只显示加载动画，文案为正在生成视频，不伪造百分比；成功后用视频播放器展示，不进入图片编辑器。图生视频可从图片结果编辑器进入，按 ADR-026 明确提交。图片生成在该项业务已指定 text_to_image 模型后，由用户明确提交，结果经授权接口展示。等待结果时，预览区只显示 GenerationLoadingCard 的生成动画，不保留上一张图片，也不伪造百分比；失败时提供重试，成功后展示生成结果。生成页不显示模型名称，用弹出面板选择分辨率、画幅和张数。宽屏下生成页为左右布局：左侧是标题和表单，右侧预览占满页面可用高度，不受左侧表单高度限制。窄于 768px 时改为上下排列，缩略图横向滚动。已生成的图片可在预览区内拖动、缩放、裁剪、旋转，并框选局部重绘、用精细选区补充蒙版、设置扩图范围；选区、蒙版、裁剪和扩图坐标使用原图像素。局部重绘默认框选区域，接入真实编辑任务；扩图复用带蒙版的图片编辑任务；消除笔尚未接入模型。生成页作品可以删除：确认后从列表移除。清理失败的提示不能写成文件已经永久删除。平台管理员在 /admin/settings 保存作品删除策略。

### 工作区视觉与交互补充

- 桌面端采用窄幅图标侧栏，图标下方保留「创作 / 资产 / 生成」文字；当前路由同时使用品牌色文字与浅色背景高亮，并设置 `aria-current`。
- 创作首页使用弱化的场景背景、居中标题、分段模式、左侧参考位暂不可用的宽幅输入框、胶囊式快捷预设与下方灵感卡片。顶部保留低存在感的创作空间切换。
- 灵感卡片是明确标注的概念参考，不属于用户资产或真实生成结果；点击仅填充并聚焦当前项目的需求草稿。预设仍由统一目录提供，未来通过项目范围 API 动态获取。
- 资产页使用紧凑的类型筛选、搜索和视图工具栏。默认意图是查看当前用户有权访问的全部空间作品，并按空间和类型筛选；该汇总尚未接入。服务未接入时在画面中央显示待接入状态，并提供回到创作的入口。不能把未查询解释为真实资产数量为零，不能在前端按空间分别请求再拼接，也不能因此开放跨空间资料或记忆。
- 移动端侧栏收进导航弹窗，预设自动换行，灵感卡片单列排列。键盘焦点、按钮标签与减少动态效果偏好必须保留。

## 9. 模型目录管理页

管理功能不放进项目工作区，工作台也不提供模型开关。宽屏使用 232px 左侧导航和右侧内容区，小于 768px 时导航收进抽屉。两个界面分开：/admin/models 只显示目录，登记从表头按钮打开对话框；/admin/assignments 只显示业务指定。目录使用紧凑表格，可按供应商、启用状态和能力下拉筛选，并按模型名称搜索；基于已返回的目录每页显示 10 条配置，不修改接口分页契约。页面先请求管理接口，只有成功后才渲染对应界面。非管理员得到 404，并按未知页面回到项目列表，不显示管理表单或拒绝说明。账户菜单中的入口只在服务端会话标明 platform_admin 后出现，不能代替接口校验。登记表单从服务端供应商目录选择供应商和模型。能力直接使用该模型的 capabilities，不单独选择；参数使用该模型声明的可选项。提交仍只有 provider、model_name、capability、parameters_schema、limits、secret_ref，密钥名称等于供应商标识，不提供密钥输入。停用后列表立即反映。目录表格按能力筛选，业务指定页为每项业务指定一个同类已启用模型。创作页不显示当前文本模型说明，也不提供发送给模型的入口；预览对话框仍只保留在本地。生成页在已指定 text_to_image 模型时，用弹出面板选择分辨率、画幅和张数，再由用户明确提交一次图片生成并展示结果。已指定 text_to_video 时，生成页可以选择时长和画幅并提交文生视频。语音和向量即使被指定也不打开调用；image_to_video 和 image_inpaint 在图片编辑器中使用已适配模型。已指定视频模型声明可接收图片时可以添加首帧参考图，否则参考图上传保持不可用。


### 管理后台视觉规范

- `/admin` 使用独立的浅色 SaaS 主题，允许在当前后台会话内切换深色。复用既有语义颜色 token；离开后台恢复官网和工作区主题。Radix Portal 中的菜单与弹窗必须跟随后台主题。
- 页面标题 24px，正文 14px，次要文字 12–13px；侧栏项 40px，输入框 38px，主按钮 36px；圆角 6–12px，以 4px 间距网格排版。禁用大面积渐变、发光和重阴影。
- 概览只从当前接口返回的配置列表计算配置总数、启用数、供应商数和停用数，不代表供应商健康状况。每行展示模型名称、供应商首字母、能力、版本、密钥引用名和状态。停用与恢复入口放入行菜单并保留确认说明。恢复后可以再次指定，停用时取消的业务指定不会自动恢复。业务指定的设定与取消用弹出提示说明结果，提示会自动关闭：成功说明已指定的模型或已取消，失败说明原因。不添加未实现的编辑、删除、复制或模型测试。
- 登记对话框最大宽度 540px。供应商和模型从服务端目录选择，能力直接展示并提交该模型 capabilities 中的每一项。声明了输入模态时，在能力下方展示文本、图片、视频或音频，只作说明，不写入提交载荷。参数只展示该模型声明的可选项，不能手写未声明参数。提交载荷及配置不可变规则保持不变。
- 首次加载使用骨架，失败提供重试；无配置与筛选无匹配采用不同空状态。刷新不发起业务写入。移动端导航使用带焦点管理的 Radix Dialog，工具栏换行，表格在容器内横向滚动。


### 生成工作室布局

生成页采用左侧创作面板与右侧大画布：左侧为图片/视频切换、描述输入、暂不可用的参考素材入口，以及生成设置与全宽提交按钮；右侧保留加载动画、失败重试、视频播放器和图像编辑器。预览区不设顶部标题栏和上下边框，历史结果在右侧独立纵向缩略图栏呈现；不显示 CREATION STUDIO 或生成工作室标题。短屏下提示词面板内部滚动，窄屏上下排列。

示例按钮仅在描述为空时填入文字，不自动发起模型调用。图片仍使用既有参数面板，视频只展示当前支持的时长与画幅；不仿造竞品的模型选择、首尾帧、音画同步、会员或积分功能。页面不改变原有请求、幂等键及任务轮询契约。

## 视频编辑器

ADR-022 已批准 Remotion Player、dnd-kit 与仅作用于本地编辑会话的 Zustand。详见 [视频编辑器契约](video-editor.md)。服务端工程和任务仍由 TanStack Query 管理。生成结果增加编辑入口，不改变原有生成调用。

### 管理控制台导航扩展（已实现 UI）

`/admin` 展示总览，统计只来自真实模型目录，不代表供应商健康或平台运营指标。侧栏按工作台、平台运营、模型与服务、安全与治理分组；当前路由高亮，窄屏继续使用抽屉。

已接入：`/admin/models` 模型目录、`/admin/assignments` 业务指定、`/admin/users` 用户管理、`/admin/tasks` 生成任务、`/admin/assets` 资产管理、`/admin/exports` 视频导出。规划入口：`/admin/moderation` 内容审核、`/admin/audit` 操作审计。规划页面明确标注待接入，展示功能范围，不展示虚构数据或可执行管理操作。未知后台子路由回到总览。

所有入口沿用服务端平台管理员检查；用户管理和任务元数据访问范围按 ADR-024 扩展。ADR-025 增加资产与导出元数据盘点、排队导出取消；审核及私有内容访问仍未授权。

### 用户与任务后台（ADR-024）

`/admin/users` 已接入真实用户列表、邮箱搜索、状态筛选及每页 20 条分页。支持普通账号停用、恢复、撤销会话；管理员账号受保护，写入前确认，提交中禁用，409 保留错误提示，关闭后刷新再操作。

`/admin/tasks` 已接入图片/视频任务元数据列表、状态/供应商/归属/时间/核对标志筛选、详情及排队任务取消。列表每 10 秒刷新，隐藏页面不轮询，详情终态停止轮询。取消按钮只依据服务端 allowed_actions；当前图片/视频适配器都只允许 queued 取消，运行中不伪造取消成功。

这两个入口不再标注待接入。审核与审计两个剩余规划入口仍不提供操作。

### 资产与视频导出后台（ADR-025）

资产页将用户上传与项目资产分成两个标签，切换后清除旧筛选与分页，查询缓存包含身份、来源和筛选。类型、状态、归属 UUID、记录 UUID、带时区时间筛选都由服务端执行，每页 20 条。详情仅展示安全元数据；大小统计包含当前筛选内所有非 deleted 登记（含 pending），不是存储实际容量或费用。

视频导出页查询 editor_renders，显示状态、归属、快照中验证过的分辨率、帧率与时长。工程版本与精确耗时未记录，显示暂不可用。列表每 10 秒轮询，页面隐藏暂停；详情到终态停止。只有服务端 allowed_actions 含 cancel 时提供确认按钮，409 保留错误并提示刷新，不伪造取消成功。


### 图片结果操作（ADR-026）

局部重绘与生成视频使用当前编辑画布快照，提交前弹窗展示参考图、提示词和服务端支持的参数。局部重绘默认进入框选区域，可移动和调整矩形，并保留蒙版笔作为精细选区；生成按钮与回车共用同一套校验。模型缺失/未适配时明确显示原因。点击打开不创建任务，用户确认后上传并提交；内容不变时网络重试固定输入与幂等键，修改描述后使用新的提交标识。状态使用 TanStack Query、项目级缓存与终态停止轮询。可以关闭后从生成记录查看；成功后可切换原图与结果，并选择使用结果、继续调整或保留原图。蒙版画笔与橡皮采用同一图片坐标，橡皮恢复保留区。


ADR-027：图片操作统一使用图片生成模型，视频操作统一使用视频生成模型。image_inpaint/image_to_video 仅表示操作类型，不再提供独立指定或新配置类别；历史记录保留且不影响新请求，已排队任务保持原模型快照。Qwen Image 2.0、3.0 的选区通过参考图引导，再由应用蒙版合成保证区域外不变，不宣称供应商原生支持 mask。

局部重绘框选完成后直接打开确认弹窗，取消画布上的二次描述输入栏；当前图片模型未适配时仍然打开，并在弹窗中说明原因。关闭后可用「输入重绘内容」再次打开。弹窗按原图归一化坐标叠加选区边框。成功结果支持原图/结果左右拖动对比及键盘操作。失败后保留输入，明确操作后可修改描述并创建新的生成意图。


### 模型详情与能力展示

- 管理模型目录将视频类别显示为“视频”，另用文生视频、图生视频等标签表达具体能力。标签来自目录声明；旧版明确的 `-t2v` / `-i2v` 变体按其模式显示，不以视频类别推断所有模式都可用。
- `/admin/models/details?provider=...&model=...&config=...` 在管理控制台内展示模型详情。登记弹窗与目录行均提供入口，未登记模型也可查看详情。
- 详情区分当前供应商参数范围和已登记版本的参数快照；目录没有声明的能力、限制不得编造。
- 未登记能力调用已有登记接口；已启用版本可停用，已停用版本可启用。停用前提示取消业务指定，启用不会自动恢复指定。操作后刷新模型与业务指定查询。多能力登记部分成功时保留已成功版本，重试仅登记缺失能力。

### 图片扩图

扩图复用统一图片模型和现有带蒙版图片编辑任务。前端导出扩展画布、原图保护蒙版（原图为黑、新增区域为白），服务端沿用项目隔离、幂等、异步生成和蒙版合成。选择比例、拖动边框或四周扩展后进入描述确认弹窗。未确认使用结果前不得修改原编辑文档；取消、失败与无扩展范围不应写入编辑历史。完成后支持对比、继续调整及保存资产。新增区域与原图衔接质量取决于模型，原图区域通过合成保护。

扩图交互更新（2026-10-06）：在中央画布内编辑，不打开生成弹窗。默认四边各扩展原图对应边长的 20%，支持八方向手柄、自由及固定比例、单方向/四周快捷扩展。工具栏提供最多 800 字符的扩展内容输入，默认沿用当前作品提示词，并显示字符数；修改描述会生成新的幂等请求签名。原图像素尺寸固定，视口坐标经统一变换换算回图像坐标；窗口尺寸变化不修改扩展数据。尺寸上限来自 image-editor-options 的 limits（已登记模型限制与平台解码上限取最小值）。失败保留范围和描述；重置只重置边距；重复点击由同步互斥与服务端幂等双重约束；成功自动选中新资产并退出扩图。切换图片时取消旧请求监听、释放 object URL，忽略迟到结果。

请求使用既有两阶段协议：上传目标画布与黑白蒙版获得 input_id，再提交图片任务，parameters.outpaint 包含 original_width/height、target_width/height、offset_x/y、extension 与 blend_size。描述默认沿用当前资产对应生成记录的 prompt；未提供的 seed、negative_prompt 或模型不支持的参数不臆造、不透传。

扩图高级设置默认收起：融合宽度自动/小/中/大，不再提供二次接缝修复开关，单次模型生成完成扩图与边界重建。提示保护中心而非声称自动主体分割。进度展示准备画布、生成与融合的客户端阶段；服务端暂无细粒度阶段接口，不用定时器伪造各模型阶段完成。

Skill 关联升级：后台可在新增/编辑时选择“仅保存到目录”或“扩图 · image.outpainting”。关联并激活后补充指令进入新扩图任务，停用阻止新任务；删除提示回退内置技能。旧的“激活不会进入生成”的说明仅适用于未关联目录项。

图片生成页按 image_to_image 可用性开放参考图片上传。选择图片后显示“图生图片”，提交图片与描述；移除后恢复“文生图片”。不支持的参考图不得静默忽略，提示移除或由管理员配置支持的统一图片模型。

### 资产瀑布流与个人主页
资产提供网格、瀑布流、列表三种布局。MasonryGallery 作为共享纯布局组件，个人主页使用同一组件。生成作品支持确认公开和撤回，默认私密，上传素材不公开。访客入口 `/u/{userId}` 只展示显式公开作品。

### 创意对话
创作页发送需求到真实会话，支持历史切换、新对话、失败重试和服务器状态轮询。图片方案在消息内点击生成并展示持久化结果；视频方案进入生成页确认。上传入口暂不开放，不声称文本 DeepSeek 能直接理解图片。

对话图片交互更新：用户已授权识别图片生成意图后直接生成。Worker 在新回复完成校验时，同事务创建图片任务并关联消息；历史读取不触发生成，失败仅显式重试。文字在图片容器外，生成期间复用动画骨架，工具栏位于回复底部。
