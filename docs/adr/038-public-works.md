# ADR-038: 用户选择公开的作品与个人主页

## Status
Accepted — 用户明确要求资产中选择公开作品并在个人主页展示。

## Decision
生成资产默认私密，以 PostgreSQL assets.published_at 为唯一发布事实。仅作者在仍有访问权的项目内可公开或撤回自己的就绪图片/视频。公开仅披露作品媒体、尺寸、类型、发布时间，不披露邮箱、原始提示词、对象键或私有项目元数据。

新增匿名只读个人作品列表和内容入口，作为项目隔离的明确例外。每次访问检查公开状态、资产删除状态、作者启用状态、项目存在且作者仍有成员权限。撤回后不再签发新地址；已签发的对象存储临时地址最长仍有效 5 分钟。不修改存储桶为公共桶。

上传素材仍为个人私有素材，不自动公开。资产视图与主页共用无业务逻辑的瀑布流组件，无新增依赖。首页公开视图按用户分页，不产生搜索索引。
