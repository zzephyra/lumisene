# ADR-051：视频制作工作流简化与费用保护

Status: Accepted — 用户完整重构需求明确授权。

保留六步持久化索引，对外整合基础配置、素材准备、分镜规划、确认生成。取消固定摘要，分镜编辑使用独立 Drawer。规划质量提醒不作为生成硬性限制；版本、权限、媒体引用和时长仍由服务端校验。

修订 ADR-050 的未知费用勾选授权：当前无报价/余额能力时，新的付费制作执行在服务端拒绝，旧 acknowledge_unpriced 参数仅保留兼容，不再作为放行依据。已有媒体可继续查看和本地合成。未来接入真实计费服务后再开放报价与余额校验，不伪造免费或额度。

费用门槛已由 [ADR-052](052-defer-production-billing.md) 替代，其余布局决策继续有效。
