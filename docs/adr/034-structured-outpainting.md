# ADR-034: 结构化扩图流水线

Superseded by [ADR-035](035-native-outpainting.md) — 原方案历史记录。

Accepted — 2026-10-09，用户明确授权整体重构。

保留现有项目隔离、统一图片模型、Skill Executor、异步任务与资产存储；替换扩图执行核心。内部白色=可编辑，适配器负责 Qwen 引导蒙版与 OpenAI 透明蒙版转换。

规划分为任务分类、原图分析、布局、分区蒙版、分任务提示词、单次生成、分区合成。背景估计采用边界颜色和前景差异启发式，复杂背景标为低置信度，不宣称具有语义分割。新增主体任务保留至少估计主体跨度的 1.2 倍；前端先分析并展示调整后的画布，再由用户执行，不暗中付费生成。

调试包复用 PG Asset（FILE）与私有对象存储，不新增平行存储系统；任务快照记录调试资产 ID。包含原图、目标画布、前景估计、可编辑蒙版、融合蒙版、最终 Skill 提示词、模型原始图像和最终合成。纯色背景直接延展时没有模型原始输出，execution.txt 记录未调用模型。失败时保留已完成阶段。读取经现有项目鉴权与资产 content 路由，不记录密钥。

GET 项目任务 outpaint-debug 返回私有资产下载路径；POST 项目 outpaint-plan 仅分析，不调用模型、不创建付费任务。模型参数上限在规划和执行均检查。

三类模板随 SkillSnapshot 固化。历史 seam_refinement 字段只为兼容请求保留，不执行二次调用。历史合成辅助函数保留用于旧接口测试与普通重绘，新扩图执行不再调用它们。

局限：像素检查不能证明模型生成了正确语义，也不能可靠检测所有重叠、断层和重复纹理。真实模型视觉验收独立于替身测试，未验证必须明确报告。Debug 文件沿用资产权限与生命周期，暂不新增自动清理策略。
