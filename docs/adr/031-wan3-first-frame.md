# ADR-031: wan3.0-video 用首帧媒体生成视频

## Status

Accepted — 2026-10-05。用户要求：视频模型声明支持图片输入时，可以添加参考图片；图片上的生成视频使用当前视频模型，不另换模型。

## Decision

- 图生视频继续复用已指定的 `text_to_video` 模型。目录里该模型的 `inputs` 含 `image` 时，生成页可以添加参考图片，图片编辑器的生成视频可以提交当前画布。未声明图片输入的模型不接收参考图，也不改走另一个模型。
- `wan3.0-video` 的首帧放在 `input.media`，类型为 `first_frame`，比例使用 `adaptive`。既有 Wan 2.x 图生视频模型仍使用 `img_url`。时长仍为 5 秒，清晰度来自已登记配置。
- 参考图先保存为当前项目的私有生成输入，再由 Worker 在事务外提交。不接受任意外部图片地址。

## Consequences

视频 Worker 需要加载这次适配器变更后才会按新协议提交。其他未验证协议的模型即使写了图片输入，也不能默认套用这一请求格式。
