# ADR-030: 供应商目录写在模型端点 YAML

## Status

Accepted — 2026-10-04。用户要求登记模型时的供应商、可选模型和参数都由 `model-endpoints.yaml` 规定，后续选择围绕这份目录。

## Decision

- 未提交的 `backend/model-endpoints.yaml` 继续保存地址和密钥。每个端点还可以声明中英文别名、可登记的模型、该模型支持的参数选项，以及输入模态。输入模态只说明模型能接收文本、图片、视频或音频，不新增登记能力，也不写入已发布配置。
- 端点名称同时是登记时的供应商和 `secret_ref`。管理页只展示声明了模型的端点，不返回地址或密钥。
- 端点声明了模型时，登记必须选用其中的模型、能力和参数，不能另写未声明的组合。没有声明模型的端点仍允许原有登记方式，供测试和尚未填写目录的密钥名称使用。
- 已发布的 `model_configs` 仍然不可改写。业务指定继续指向已登记配置，不直接改写 YAML。

## Consequences

改文件后需要重新加载读取配置的进程。参数选项是选择范围，不代替供应商协议验证；生成请求仍由服务端按已登记配置校验。
